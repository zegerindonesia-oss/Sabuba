# SABUBA — DESIGN & MOTION SYSTEM

## Brand feeling
Modern Indonesian × Warm Family × Premium Accessible × Scalable

## Composition
- One key message per slide.
- Large typography.
- 60–70% visual area where appropriate.
- Use whitespace.
- Avoid dense paragraphs.
- Use short sentences.
- Numbers should be visually dominant.
- Charts should be simple and credible.

## Photography
Food:
- cinematic morning light
- visible steam
- claypot texture
- close-up toppings
- appetizing but realistic

People:
- Indonesian families
- workers/commuters
- natural expressions
- authentic environments

Business:
- real Sabuba assets first
- conceptual future outlet visuals only when clearly marked as conceptual

## Motion
Use subtle premium motion:
- slow camera push
- steam movement
- text reveal
- number count-up
- map route animation
- system-flow animation
- product ingredient movement
- smooth page transitions

Avoid:
- aggressive zooms
- excessive particles
- flashy corporate transitions
- generic AI effects

## Web
Hero section:
full-screen cinematic breakfast visual + headline.

Scroll storytelling:
Problem → Opportunity → Product → System → Format → Vision → Market → Economics → Partnership → Roadmap → CTA.

## PDF
Use 16:9 landscape.
Export high-resolution.
Keep text readable when printed/viewed on phone.
